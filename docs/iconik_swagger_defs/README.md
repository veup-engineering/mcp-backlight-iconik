# Iconik OpenAPI/Swagger specs

This folder contains the Iconik Swagger/OpenAPI specs downloaded from:
- https://app.iconik.io/docs/swagger.html

Files:
- acls.json
- assets.json
- auth.json
- automations.json
- files.json
- jobs.json
- metadata.json
- ml.json
- notifications.json
- search.json
- settings.json
- stats.json
- transcode.json
- users.json
- users-notifications.json

Usage with Codex:
- Tell me which spec file(s) to use.
- Tell me the endpoint or operation you want configured.
- Provide any auth/header details and your Iconik API host.

Example request:
"Use docs/iconik/assets.json and docs/iconik/metadata.json. Build a request to update metadata for an asset. Host: https://YOURDOMAIN.iconik.io. Auth: App-ID + Auth-Token headers."
